# 适应性战略

战略不是替战术预写所有动作，而是在行动前识别最后必须守住的条件，让多方力量更可能朝目标汇合。现实不受单一意志控制；策略必须能被反馈修正。

## 分析

1. 明确最终要成的事，并把方法、身份、面子、已有承诺从目标中剥离。不做决定同样是一种决定，要写出其后果。
2. 描述系统中的参与者、资源、利益、依赖、竞争压力和阶段。寻找让系统继续存在或发展的“养分”，不要把领导意愿、组织边界或当前模块当成自然规律。
3. 区分战略与战术：
   - 战略只保留战术现场容易忘记、但决定方向的少数条件；
   - 战术根据当时事实取得具体结果，可以修正原计划。
4. 守弱：把判断落在原始目标、已验证事实、真实能力和未解决弱点上；对术语、方案、身份与个人正确性保持柔软。强项会自然发挥，不要用展示强项替代解决弱点。
5. 法自然：识别不靠额外控制也会发生的动力，删除不必要的管理和依赖；只引导关键边界。它不是消极等待，也不等同于堆叠备用计划。
6. 单独评估 Plan B、冗余和风险缓解的成本。它们是主动策略，应与顺应系统动力分开判断。
7. 选择可逐步验证、可暴露错误、可在反馈中调边界的路径。标出阶段变化后控制要素会如何迁移。
8. 检查公开规则、私下收益与参与者激励是否同向。长期冲突通常会让表面策略失效。

## 输出

- 原始目标与时间尺度；
- 系统动力、参与者和生存条件；
- 必须守住的“弱”与可调整的“名”；
- 战略条件和战术自由度；
- 选择做什么、不做什么；
- 不应主动控制的部分；
- 风险策略及其成本；
- 反馈信号、转向触发器和失效条件。

不要把“守弱”解释为示弱或退让，也不要把“自然”解释为听天由命。需要原始概念和工程案例时，读取 [references/evidence.md](references/evidence.md)。
